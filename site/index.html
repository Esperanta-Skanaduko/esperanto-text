esperanto-text

The first obstacle for every learner is typing ĉ ĝ ĥ ĵ ŝ ŭ. This library converts between the x-system (cxu), the h-system (chu) and real letters (ĉu), and turns typing into the real letters as it happens.

  • TypeScript
  • No dependencies
  • DOM helper
  • React hook
  • MIT

Use it

npm install esperanto-text

Convert text

import { toUnicode, toXSystem, toHSystem, detectSpelling } from 'esperanto-text';

toUnicode('Morgaux estas jxauxdo');   // 'Morgaŭ estas ĵaŭdo'
toXSystem('Ĉu vi ŝatas ĝin?');        // 'Cxu vi sxatas gxin?'
toHSystem('ĵaŭdo');                   // 'jhaudo'
detectSpelling('cxu');                // 'x'

Any input or textarea

import { attachEsperantoInput } from 'esperanto-text/dom';

const detach = attachEsperantoInput(document.querySelector('textarea'), { x: true, h: false });

React

import { useEsperantoInput } from 'esperanto-text/react';

const Field = () => {
  const { inputProps } = useEsperantoInput('');
  return <input {...inputProps} lang="eo" />;
};

Limits you should know

The x-system is exact. The h-system is a best effort. In the h-system ŭ is a plain u, and ch, sh or au can also be ordinary letters in a compound, as in flughaveno (flugi + haveno) or traurba. A short list of known cases is protected, and you can add your own with the exceptions option. Other compounds will be converted wrongly, so check h-system output.

Foreign words such as Linux or Redux contain ux; they are protected by default (protectedWords). URLs and e-mail addresses are never touched.
